---
description: Lista todas as oportunidades profissionais cadastradas no Opportunity Explorer
---
Execute o seguinte comando no terminal do projeto Opportunity Explorer e apresente o resultado:

```bash
npx ts-node src/index.ts oportunidades
```

Exiba a lista completa de oportunidades retornada, mostrando ID, título, empresa, tipo, nível e status de cada uma.

Se ocorrer algum erro na execução, informe o erro com clareza.
